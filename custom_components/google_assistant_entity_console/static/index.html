Prompt Variable Reference Glossary
{entity_id}
The unique Home Assistant identifier of the target device (e.g., light.living_room_overhead).
{friendly_name}
The user-defined display name or target friendly name of the device (e.g., Living Room Overhead).
{room_context}
A detailed semicolon-separated list of all other entities located in the target room. Includes their IDs, display names, and any current nicknames (e.g. light.desk (name: Desk Lamp, current nicknames: ['reading light'])).
{user_intent}
The smart filtering intent criteria entered by the user (e.g. expose all kitchen lights and smart switches).
{entities_list}
A serialized JSON array of all active candidate devices to analyze, containing entity_id, name, and domain keys.
